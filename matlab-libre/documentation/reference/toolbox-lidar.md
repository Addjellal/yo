# Toolbox `lidar`

```
% Lidar Toolbox — nuages de points.
%
%   pointCloudFromRanges - Nuage à partir de distances et d'angles
%   voxelDownsample      - Sous-échantillonnage par voxels
%   fitPlaneRansac       - Plan dominant par RANSAC
%   icpRegister          - Recalage par ICP (2-D)
```

## `fitPlaneRansac`

```
FITPLANERANSAC Droite (2-D) ou plan (3-D) dominant, par RANSAC.
```

## `icpRegister`

```
ICPREGISTER Recalage rigide 2-D par ICP.
```

## `pointCloudFromRanges`

```
POINTCLOUDFROMRANGES Nuage cartésien à partir d'un balayage polaire.
```

## `voxelDownsample`

```
VOXELDOWNSAMPLE Un point par cellule de la grille, au barycentre.
```
