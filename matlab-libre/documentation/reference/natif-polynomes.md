# Polynomes et interpolation

Fonctions natives du groupe `polynomes`.

## `deconv`

```
deconv  Division polynomiale.
```

## `interp1`

```
interp1  Interpolation 1-D.
```

## `interp2`

```
interp2  Interpolation 2-D bilineaire.
```

## `poly`

```
poly  Polynome de racines donnees.
```

## `polyder`

```
polyder  Derivee d'un polynome.
```

## `polyfit`

```
polyfit  Ajustement aux moindres carres.
```

## `polyint`

```
polyint  Primitive d'un polynome.
```

## `polyval`

```
polyval  Evalue un polynome.
```

## `polyvalm`

```
polyvalm  Evalue sur une matrice.
```

## `ppval`

```
ppval  Evalue une spline par morceaux.
```

## `roots`

```
roots  Racines d'un polynome.
```

## `spline`

```
spline  Spline cubique.
```
